# Visual style guide

The repository's original diagrams use a consistent visual language:

- Dark ink (#14243A) for titles and primary structure.
- Teal (#087E8B) for workflows and technical components.
- Amber (#D99124) for decisions and caution points.
- Pale backgrounds (#F3F7FA and #E8F3F4) for readability.
- Short labels, clear arrows, and a predictable reading order.

Prefer diagrams that explain a relationship, sequence, or decision. Keep SVG source editable in this repository; do not link to externally hosted illustrations.
