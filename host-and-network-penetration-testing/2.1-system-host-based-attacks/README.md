## Suggested study sequence
1. Build confidence with Linux navigation, files, permissions, processes, and command-line tools.
2. Learn Windows domain concepts, identities, authentication, and directory services.
3. Understand common Linux and Windows vulnerability patterns.
4. Practice host enumeration and validation in a lab.
