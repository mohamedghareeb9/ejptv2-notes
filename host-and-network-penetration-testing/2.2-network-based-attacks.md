## 1. Network foundations

### IP and MAC addresses
- IPv4 addresses are 32 bits; IPv6 addresses are 128 bits.
- An IP address identifies an interface at the network layer and is used for routing between networks.
- A MAC address identifies a network interface on a local link.
- Routers forward packets between networks and replace link-layer framing at each hop; source and destination IPs normally remain end-to-end unless translation is involved.

### ARP
ARP resolves an IPv4 address to a MAC address on the local network segment. A device broadcasts a request asking which host owns an IP; the matching host replies with its MAC. Hosts cache these mappings.

~~~bash
ip -br address
ip neigh
arp -a
~~~

ARP is a local-link protocol. It does not resolve a remote internet host's MAC address across routers.

### DNS
DNS translates names into records used to locate services.

| Record | Meaning |
|---|---|
| A | Name to IPv4 address |
| AAAA | Name to IPv6 address |
| CNAME | Alias to another name |
| MX | Mail exchanger |
| NS | Authoritative name server |
| TXT | Text data, often verification and email policy |
| PTR | Reverse lookup: address to name |
| SOA | Zone authority and timing/serial information |

~~~bash
dig example.com A
dig example.com MX
dig example.com NS
dig +short example.com
nslookup example.com
~~~

### TCP and UDP
| TCP | UDP |
|---|---|
| Connection-oriented | Connectionless |
| Reliable, ordered byte stream | No built-in delivery or ordering guarantee |
| Uses a three-way handshake | No TCP-style handshake |
| More connection state and overhead | Lower protocol overhead |

TCP connection establishment: client sends SYN, server responds SYN-ACK, client sends ACK.

Common ports to recognize:

| Port | Common service |
|---:|---|
| 21 | FTP |
| 22 | SSH |
| 23 | Telnet |
| 25 | SMTP |
| 53 | DNS |
| 80 | HTTP |
| 110 | POP3 |
| 139 | NetBIOS session service |
| 143 | IMAP |
| 443 | HTTPS |
| 445 | SMB |
| 3306 | MySQL |
| 3389 | RDP |

A port number is an indicator, not proof of which service is running. Confirm by enumeration.

## 2. Routing, ASN, and boundaries
A default gateway is the next-hop router a host uses when the destination is outside its local subnet. A subnet mask/CIDR prefix determines which addresses are considered local.

An Autonomous System (AS) is a network or group of networks managed under a common routing policy. An ASN identifies that AS in inter-domain routing. BGP exchanges reachability information between autonomous systems.

ASN and announced IP ranges can help map an organization's public network footprint. Verify ownership and scope before scanning discovered ranges.

## 3. Common network services
- **FTP:** file transfer; traditional FTP does not encrypt credentials or data.
- **SSH:** secure remote administration; protect it with strong authentication and access restrictions.
- **Telnet:** remote terminal access without transport encryption.
- **SMB:** file, printer, and resource sharing, commonly associated with TCP 445.
- **RDP:** remote desktop access, commonly associated with TCP 3389.
- **HTTP/HTTPS:** web services; HTTPS uses TLS to protect traffic in transit.
- **SMTP, POP3, IMAP:** email transport and retrieval roles.
- **MySQL:** database service; avoid broad exposure without a requirement.

An open port is not itself a vulnerability. Determine service, version, configuration, authentication requirements, and expected reachability.

## 4. Network attacks and defensive concepts

### Sniffing
Packet sniffing captures traffic visible to a network interface. It can identify hosts, protocols, connection patterns, and cleartext data. The practical notes use Wireshark and display filters.

~~~text
ip.addr == 192.168.1.10
tcp
udp
dns
http
arp
~~~

A capture filter is applied while capturing; a display filter changes which already-captured packets are shown.

### Man-in-the-middle
A MITM position allows an attacker to intercept or relay communication between parties. The practical notes connect this risk with local network behavior, rogue DHCP, and traffic redirection. Encryption and certificate validation help protect application data, but do not make every endpoint or network trustworthy.

### ARP spoofing / poisoning
ARP has no built-in authentication. On a vulnerable local network, forged ARP replies can cause devices to associate an IP address with an attacker's MAC address, redirecting local traffic.

Defenses include Dynamic ARP Inspection where supported, DHCP snooping as an input to trusted bindings, network segmentation, and monitoring for unexpected ARP changes.

### DHCP attacks
DHCP uses broadcast-based client discovery and normally uses UDP ports 67 (server) and 68 (client). Its DORA sequence is Discover, Offer, Request, Acknowledge.

A rogue DHCP server may provide malicious gateway or DNS settings. DHCP starvation attempts to exhaust the lease pool. DHCP snooping and trusted switch ports are defensive controls discussed in the practical notes.

### Denial of service
A denial-of-service attack attempts to make a service unavailable by exhausting a resource or overwhelming a service. The practical notes mention SYN floods as a TCP-related risk. Recognition and defensive understanding are the focus; do not run disruptive tests outside a controlled lab.

## 5. Recon-to-enumeration workflow
1. Confirm the target and written scope.
2. Identify local interface, address, and route.
3. Discover live hosts using an appropriate method.
4. Scan authorized hosts for TCP/UDP ports.
5. Identify services and versions.
6. Enumerate each service using protocol-specific methods.
7. Record evidence and prioritize likely weaknesses.
8. Only then consider controlled validation or exploitation.

~~~bash
ip -br address
ip route
ip neigh
~~~

## 7. Quick recap
- IP is used for network-layer addressing; MAC is used on the local link.
- ARP maps local IPv4 addresses to MAC addresses.
- DNS maps names to records; TCP is reliable and connection-oriented; UDP is connectionless.
- Common ports guide enumeration but do not prove the service.
- Sniffing observes traffic; MITM attempts to intercept or relay it.
- ARP spoofing and rogue DHCP can redirect local traffic.
- Verify scope before scanning discovered assets.
